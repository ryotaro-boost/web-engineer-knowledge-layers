# スターターガイド — 学習の入口

> **このディレクトリは何か:** Web Engineer Knowledge Layers プロジェクトを **AIコーディング時代に学び始める人向け**の最初の一歩を提供する場所。

## 前提

- 本プロジェクトは Obsidian Vault として運用される（`[[]]` リンクと Mermaid 記法を多用）
- AIコーディングエージェント（Claude Code, Cursor, Copilot 等）を日常的に使うことを前提にしている
- **「コードを書ける」ことより「AI出力を批判できる」「設計判断を下せる」**ことを身につけるための教材として設計されている
- **対象: 初学者〜ミドルエンジニアをシニアレベルに押し上げる読み物**として、じっくり何度も読み返すことで効果が出るように書かれている

## このガイドの読み方

本教材は **じっくり何度も読み込むことで効果がある読み物** として設計されている。一度で全部覚える必要はない。「ここに何かあった」と頭にインデックスがある状態が最初のゴール。

1. まず [[_starter/03_AIコーディング時代の学び方|03_AIコーディング時代の学び方]] を読み、本教材を貫く前提認識を共有する
2. 次に [[_starter/04_AI協働の基本動作|04_AI協働の基本動作]] で、プロンプト設計と検証ループの最小動作を読む
3. [[_starter/00_最小学習パス|00_最小学習パス]] の14トピックを順に通読する（各トピックの「3分で全体像」だけ拾い読みでも良い）
4. 各トピックの「理解度セルフチェック」で**自分の理解を確認しながら**読み進める。答えられなければ本文に戻って読み直す
5. 詰まったら [[_starter/02_実務症状からの逆引き|02_実務症状からの逆引き]] で関連レイヤーへ降りる
6. 数週間後に **同じトピックを読み直す**。経験を積んだ後の再読で、初読時に気づかなかった記述の意味が立ち上がる

## 学習を支える Claude Code スキル

Claude Code の `/コマンド` で起動できる学習支援機能。各トピックを開いた時、AIに何かを書かせる時、AI生成コードを評価する時、それぞれに使うスキルが用意されている。

| コマンド | 何ができるか | いつ使うか |
|---------|-------------|----------|
| `/explain-3min トピック名` | 「3分で全体像」を生成・提案 | トピックを最初に開いた時 |
| `/design-prompt 機能要件` | 関連トピックの観点を埋め込んだAIプロンプト雛形を生成 | 機能を作り始める前 |
| `/review-ai-code コード` | AI生成コードを関連トピック観点でレビュー | AIから受け取ったコードを評価する時 |
| `/refactor-topic トピック名` | 密度突出した節を抽出し`details/`への切り出しを提案 | トピックを保守する時 |

追加スキル（実装済み）:

| コマンド | 何ができるか | いつ使うか |
|---------|-------------|----------|
| `/quiz トピック名` | 動的に5問の理解度クイズを生成（最低2問は AI生成コードレビュー設問） | 学習の節目で理解確認したい時 |
| `/diagnose 症状` | 症状から関連レイヤー・トピックへの追跡経路を案内 | 実務で詰まった時 |
| `/anti-pattern-scan コード` | コードを `_anti-patterns/` 索引と全件照合 | AI生成コードを横断的にチェック |
| `/glossary 用語名` | [[_glossary/用語集\|用語集]] に新用語を追加・更新 | 教材を読んでいて詰まる用語を見つけた時 |
| `/starter-path 状況` | 学習者の状況に応じて14トピック + 週次プランをパーソナライズ | このスターターガイドを始める前に |
